# DashBoard_Spotify
# 🎵 Big Data e Tratamento de Dados — Spotify

Projeto acadêmico desenvolvido para a disciplina de **Análise de Dados e Big Data**, com foco no processo de **coleta, tratamento, análise e visualização de dados**.

O projeto utilizará uma base de dados relacionada ao **Spotify**, contendo informações sobre músicas, artistas e características das faixas. A partir desses dados, será desenvolvido um **dashboard interativo** para explorar padrões, tendências e possíveis insights.

## 🎯 Objetivo

Aplicar conceitos de tratamento e análise de grandes volumes de dados em um conjunto de dados real, passando pelas principais etapas de um fluxo de análise de dados:

* Importação dos dados;
* Limpeza e tratamento;
* Identificação e correção de dados inconsistentes;
* Transformação dos dados;
* Análise exploratória;
* Criação de métricas e indicadores;
* Visualização dos resultados em um dashboard.

## 📊 Base de Dados

A base utilizada será composta por dados relacionados ao **Spotify**.

Dependendo do conjunto de dados selecionado, poderão ser analisadas informações como:

* Nome da música;
* Artista;
* Álbum;
* Gênero musical;
* Popularidade;
* Duração da faixa;
* Ano de lançamento;
* Danceability;
* Energy;
* Valence;
* Tempo;
* Acousticness;
* Instrumentalness;
* Speechiness.

## 🔍 Análises

O projeto buscará responder perguntas como:

* Quais artistas possuem maior presença na base?
* Quais músicas apresentam maior popularidade?
* Como a popularidade das músicas varia ao longo dos anos?
* Quais gêneros aparecem com maior frequência?
* Existe relação entre características musicais e popularidade?
* Como características como `danceability`, `energy` e `valence` se relacionam?
* Existem padrões nas músicas mais populares?

Outras análises poderão ser adicionadas durante o desenvolvimento do projeto.

## 📈 Dashboard

Os dados tratados serão utilizados para a construção de um **dashboard interativo**, permitindo visualizar os principais indicadores e resultados encontrados durante a análise.

O dashboard poderá apresentar:

* Indicadores gerais da base;
* Ranking de artistas;
* Ranking de músicas;
* Distribuição de popularidade;
* Evolução temporal;
* Comparação entre gêneros;
* Relações entre características musicais;
* Filtros para exploração dos dados.
