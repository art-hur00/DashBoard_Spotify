# DashBoard_Spotify
# 🎵 Big Data e Tratamento de Dados — Spotify

Projeto acadêmico desenvolvido para a disciplina de **Análise de Dados e Big Data**, com foco no processo de **coleta, tratamento, análise e visualização de dados**.

O projeto utilizará uma base de dados relacionada ao **Spotify**, contendo informações sobre músicas, artistas e características das faixas. A partir desses dados, será desenvolvido um **dashboard interativo** para explorar padrões, tendências e possíveis insights.

## 🎯 Objetivo

Aplicar conceitos de tratamento e análise de grandes volumes de dados em um conjunto de dados real, passando pelas principais etapas de um fluxo de análise de dados:

* Importação dos dados;
* Limpeza e tratamento;
* Identificação e correção de dados inconsistentes;
* Transformação dos dados;
* Análise exploratória;
* Criação de métricas e indicadores;
* Visualização dos resultados em um dashboard.

## 📊 Base de Dados

A base utilizada será composta por dados relacionados ao **Spotify**.


Projeto desenvolvido como trabalho acadêmico da disciplina de **Análise de Dados e Big Data**, com o objetivo de aplicar conceitos estudados em aula utilizando dados reais do Spotify.
